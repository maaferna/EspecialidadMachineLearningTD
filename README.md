# Machine Learning Specialization — Talento Digital para Chile

Personal repository with the coursework and graded projects of the **Machine Learning Specialization** by
Talento Digital para Chile (executed by Kibernum): 12 modules plus a final project, May–October 2025,
credential issued December 2025. Each graded project has its own README with setup, metrics and figures.

| Module | Graded project | Folder |
|---|---|---|
| Optimization methods | Gradient descent vs. stochastic gradient descent on linear regression, with tests | `Modulo3EvalMod_MarcoParra/` |
| Model optimization | Hyperparameter tuning compared: GridSearch, RandomSearch, Optuna, Ray Tune, scikit-optimize, Hyperopt | `Modulo4EvalMarcoParrra/` |
| Advanced regression and classification | Credit scoring with interpretability | `Modulo5Clase6EvalModMarcoParra/` |
| Advanced unsupervised models | Segmentation and anomaly detection in chronic patients | `Modulo6EvalModularMarcoParra/` |
| Modern neural models | Credit scoring with deep networks (DNN vs. tabular ResNet), cost-sensitive evaluation, SHAP | `Modulo7EvalModularMarcoParra/` |
| Natural language processing | Clinical-note classification with an ethics focus | `Modulo8EvalModularMarcoParra/` |
| Interpretability and explainability | LIME and SHAP on predictive models | `Modulo9EvalModularMarcoParra/` |
| Model deployment | ML API containerized with Docker and micromamba | `Modulo10EvaModularMarcoParra/` |

Class exercises live in the `ModuloNClaseM…` folders.
